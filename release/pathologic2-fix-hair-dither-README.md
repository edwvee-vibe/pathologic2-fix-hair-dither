# Pathologic 2 Hair Dither Fix

Removes the checkerboard pattern on soft hair edges and eyelashes. Best with DLAA.
For game version 2.1.31648 (current Steam version) and 2.1.31563.

## Enable

1. Close the game.
2. Put all `pathologic2-fix-hair-dither*` files into the game folder (the one with `Pathologic.exe`).
3. Double-click `pathologic2-fix-hair-dither-enable.bat`. Wait for `Done.` and press any key.

After a game update or a Steam file check, run it again.

## Disable

Close the game and double-click `pathologic2-fix-hair-dither-disable.bat`. The original game file is put back.

## Uninstall

Disable it (see above), then delete the `pathologic2-fix-hair-dither*` files from the game folder.

If Windows says "Windows protected your PC", click *More info* > *Run anyway*.
